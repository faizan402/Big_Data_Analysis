# 📊 YouTube Big Data Analysis using PySpark

This project is focused on analyzing YouTube video data using PySpark and Apache Spark. The main goal was to understand how big data tools can process and analyze large datasets more efficiently compared to traditional tools like Pandas.

The dataset includes information such as video titles, categories, views, likes, and channel details. Using PySpark, the data was cleaned, transformed, and analyzed to discover useful insights about video performance and audience engagement.

Throughout the project, different data analysis techniques were applied, including:

* Data cleaning and preprocessing
* Grouping and aggregation
* Feature engineering
* Exploratory Data Analysis (EDA)
* Data visualization

Some of the analysis performed in this project includes:

* Identifying the most popular video categories
* Finding videos with the highest views
* Comparing engagement across categories
* Analyzing the relationship between views and likes

To visualize the insights, graphs such as bar charts, histograms, scatter plots, and pie charts were created using Matplotlib.

This project also helped in understanding important big data concepts such as:

* Distributed data processing
* Lazy evaluation
* Transformations and actions in Spark
* Parallel processing using partitions
